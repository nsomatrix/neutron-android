# Neutron

**Neutron** is a modern J2ME emulator for Android, developed by **[nsomatrix](https://github.com/nsomatrix)**.

[![GitHub Repository](https://img.shields.io/badge/GitHub-nsomatrix%2Fneutron--android-blue?logo=github)](https://github.com/nsomatrix/neutron-android)
[![License](https://img.shields.io/badge/License-Apache%202.0-green.svg)](LICENSE)

## Overview

Neutron is a high-performance J2ME (Java Micro Edition) emulator for Android devices. It supports most 2D and 3D MIDP applications and games, including full support for Mascot Capsule 3D.

### Key Features
- **Virtual Keyboard**: Customizable touch key mappings and layouts.
- **Per-App Settings**: Dedicated graphics, performance, and control profiles for each MIDlet.
- **Scaling & Rendering**: Flexible screen scaling, filtering, and shader options.
- **3D Graphics Support**: Built-in 3D rendering engine and Mascot Capsule 3D support.

## System Requirements
- **Android OS**: Android 4.0+ (API Level 14+)

## Usage Tips
- **Performance**: Enabling texture filtering in some titles may impact performance. Disable filtering if a game runs slowly.
- **Flickering Fix**: If you experience screen flickering, try enabling **"Immediate processing mode"** in the app configuration settings.
